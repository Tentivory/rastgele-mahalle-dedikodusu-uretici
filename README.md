# Rastgele Mahalle Dedikodusu Üretici

## Bu Ne Lan?

Bu proje, insanlığın en büyük sorunlarından biri olan "mahalle dedikodusu kıtlığı"nı çözmek için geliştirilmiştir. Bilimsel araştırmalar (ki hiçbir kaynak göstermiyoruz çünkü gerek yok) göstermiştir ki insanlar günde en az 17 dedikodu üretmezlerse depresyona girerler. Bu yazılım, o açığı kapatır.

### Özellikler
- %100 uydurma dedikodular
- Mahalle atmosferini bozmaz (aslinda bozar)
- Bilim kurulu tarafından onaylanmamıştır
- Çay içmeden çalışmaz (yanlış, çalışır)

## Nasıl Kullanılır?

```bash
python dedikodu.py
```

Çıktıyı okuyun, gülün, unutun. Asla gerçek insanlara anlatmayın yoksa mahkeme koridorlarında "dedikodu davası" açılır.

## Uyarılar
- Bu program yasal değildir (yalan).
- Kullanımı sırasında çay bitmemesi önerilir.
- Kediler programın çalıştığını duyunca balkona çıkar.
